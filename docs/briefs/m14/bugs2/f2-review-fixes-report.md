## Decisions

1. **What "the player's own area" is.** `CatPose.of` takes an optional `area`; the board painter leaves it the whole field, the mirror passes its own box, and the split layout passes the half it draws. The head hangs from `area.top` and is still centred/clamped inside the board's columns.
2. **The 80 % floor at a short top.** `shrink = (aim.dy - area.top) / full`, clamped to 0.8, so with the board at y 13 and a full head 18.4 high the head is 14.72 high and its bottom sits 1.72 over the board's top edge; the brief allows this ("shrinks no further than 80 %").
3. **No paw out of sight.** `paintCat` returns before drawing anything when `head.bottom <= area.top`, so the leave's paw goes up with the head, and the tip still lerps to the moving shoulder.
4. **The brief's "same-shape pair 5 % apart".** `twinToleranceShare` is 3 % of `PieceShape.size` (the diameter), which is 6 % of the radius, so a pair a 5 % radius apart is still a twin and cannot be used for the "stays wrong with both slots hinted" test. The test uses a shape a tenth bigger (radii 14.32 and 15.65, 8.5 % apart, corners ~5 % of the size) whose mirror and turn readings are null both ways.
5. **The "(you)" text lives in `test_game`.** `party_host` already has an `ArenaText`, so the new one is `ArenaBarText` in `packages/test_game/lib/src/arena_text.dart`, exported by `test_game.dart`; `ArenaBoard`/`ArenaHud` take an optional `ownId`, so a TV marks nobody.
6. **Pictures to commit.** Only the four `docs/design/m14-cat-*.png` are this job's; the test run also rewrote `docs/design/m13-placed-look.png`, `docs/design/puzzles/{butterfly,car,rocket,train}.png` and `site/shots/*.png`, which are to be left out of the commit.
