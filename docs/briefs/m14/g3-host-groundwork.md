Four small pieces the M14 features stand on, all on the host side. Claude's design:
1. **The empty-rounds record.** Both games' `abandon()` record a `round_end` with only `{reason: abandoned}`; `SessionRecorder.onRecord` turns that into `roundEnded(timeS: 0, modes: {})`, and the stats gain a round with no players and no time. An abandoned round must add no round (and no rounds-per-format count) to the stats. Keep `onRecord` under 60 lines (it is 52): a helper for the `round_end` branch is fine.
2. **The round music's place across a hidden app** (R4 finding 8). Today a hidden app stops the round's loop and a shown app starts it again from the top. Wanted: the round's music resumes where it was, as it does after the pause menu; the lobby music keeps doing what it does today. Hiding still silences it at once. If the round ended or its screen closed while hidden, nothing resumes. Update look-and-sound.md section 8's line on the hidden app to say this.
3. **The Arena's sound keys.** The ten files job a1 made are in `assets/audio/` and play nothing: `dash`, `bump`, `bump_big`, `coin`, `coin_gold`, `coin_lost`, `coin_appear`, `arena`, `arena_hurry`, `arena_final`. Add them to the `SoundKey` list with those wire spellings, a CREDITS.md row each (made with `tools/audio/arena_sounds.dart` and `arena_music.dart`, CC0 1.0, what each is for from the a1 report), the Audio paragraph's list of names, and `sound_keys_test.dart`'s spellings. No game plays them yet (job b1 does); `MusicLoop` is not changed here.
4. **`RoundResult`** in `game_kit` (design N1): an immutable value each game's screen will hand to its `onFinished`, which the party night reads. Fields: `game` (the game's name), `winners` (a set of player ids, empty for none), `draw`, `points` (player id → this round's points, already scaled), `stats` (player id → named counters for the awards, e.g. `snaps`, `coins`), `lines` (player id → that player's line for a results card: outcome `win`/`loss`/`draw`/`done`, optional time in seconds, optional count and what it counts, `pieces` or `coins`). Unmodifiable collections; a `points` or `lines` entry for a player id not in the round is allowed (nothing checks the roster here). Export it from `game_kit.dart`. Nothing uses it yet.
