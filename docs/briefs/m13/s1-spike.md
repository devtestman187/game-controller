2. `ToyShaders` (lib/src/toy_shaders.dart): `static Future<ToyShaders> load()` loads `FragmentProgram.fromAsset('packages/toy_look/shaders/toy_shade.frag')`, timing it (`loadMs`). Uniforms are set by name (`getUniformFloat`, `getUniformVec2`, `getUniformVec4` as available in Flutter 3.47; if the name API isn't there, by index in the shader's order, and say so in the report).
3. `toyShape(Canvas canvas, Path path, Color color, ToyShapeStyle style, {FragmentProgram? shade})` (lib/src/toy_shape.dart), the one call that draws a game object, in this order: (a) the shadow: the path shifted by `style.shadowOffset`, filled with `style.ink` at `style.shadowAlpha`; (b) the body: with `shade`, a `FragmentShader` from it with uOrigin/uSize = the path's bounds, uColor = the colour, uLight = (-0.55, -0.65), set as the paint's shader; without it, the fallback: a `LinearGradient` from the bounds' top-left to bottom-right with hard stops: 0–0.30 highlight (`Color.lerp(color, white, 0.38)`), 0.30–0.75 the colour, 0.75–1 shade (`Color.lerp(color, black, 0.26)`), plus a white oval glint (opacity 0.75) at 27% across and 24% down the bounds, 8% by 5% of the bounds, turned −30°; (c) the outline: the path stroked in `style.ink`, `style.outlineWidth`, round joins and caps. `ToyShapeStyle` holds `ink`, `outlineWidth`, `shadowOffset`, `shadowAlpha` (const constructor, defaults ink 0xFF1E1646, 3.0, Offset(2.25, 3), 0.35). Shapes with different colours in one frame must each keep their own colour: if one reused `FragmentShader` can't do that, make one per draw and say which in the report.
4. `ShaderSpikeScreen` in `tv_test_app/lib/src/ui/shader_spike_screen.dart`, opened by a new "Look test" button next to Latency on the TV home (same style as the other test tool buttons). It loads `ToyShaders` when opened and shows: "Shader: on (loaded in N ms)" or "Shader: off: <error>"; a row of four shapes (circle, rounded square, triangle, wide rounded bar) in the four player colours drawn with `toyShape` and the shader, and the same row below drawn with the fallback, each row labelled; the shapes turn slowly (one turn per 8 s) so frames keep coming; a "Stress: off/on" button that adds 60 more shapes (all colours, both kinds); and the frame time over the last 120 frames (average and worst, ms, from `SchedulerBinding.addTimingsCallback`, build plus raster). Background 0xFF7CC8F8 (Sunny). Controller navigation like the other test screens (Back leaves). Plain Material widgets for the labels and buttons: the look of this screen isn't the job.
