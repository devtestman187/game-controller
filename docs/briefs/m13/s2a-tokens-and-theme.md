3. The Look setting (D1): `enum LookChoice { auto, sunny, night }` with `static LookChoice fromName(String? name)` (unknown or null gives auto) so the apps can save it by `.name`. `enum ToyPalette { sunny, night }` and a pure `ToyPalette paletteFor(LookChoice choice, DateTime localTime)`: sunny and night pick themselves; auto is sunny from 7:00 inclusive to 19:00 exclusive, local time, night otherwise. No clock is read inside toy_look: the caller passes the time (it decides when a screen opens, never mid-round). `ToyColors.of(ToyPalette)` returns the matching const.
4. Sizes: `ToySizes` consts from section 3: outline 3 (menus) and 4 (TV), the widgets' shadow offset Offset(3, 4) (3 right, 4 down), card corner 16, the spacing scale 4, 8, 12, 16, 24, 32, focus ring 4. Leave toy_shape.dart's ToyShapeStyle defaults alone (the game pieces are tuned in step 4).
5. Type: `ToyType` with `title`, `button`, `clock` (Fredoka 600) and `body` (Nunito 700) TextStyles, at TV sizes (`ToyType.tv`: 56, 28, 56, 22) and phone sizes (`ToyType.phone`: 32, 18, 32, 15). Each style sets `fontFamily` and `package: 'toy_look'`, the `fontWeight` and the matching `fontVariations` (`FontVariation('wght', 600 or 700)`), because a variable font picks its weight from the axis on some platforms. Colour isn't part of the type (the theme and widgets add it). Declare both families under `flutter: fonts:` in toy_look's pubspec and the two OFL.txt files under `assets:`.
6. Font licences (D13): `Future<void> registerToyFontLicenses({Future<String> Function(String key)? load})` adds one `LicenseEntryWithLineBreaks` per font (packages `['Fredoka']` and `['Nunito']`) to `LicenseRegistry`, reading each OFL.txt through `load` (default `rootBundle.loadString` with the `packages/toy_look/...` key). The apps call it in step 3.
7. `ToyLook` (final class, const constructor): `palette` (ToyPalette), `colors`, `sizes`, `type`, `shade` (the body shader's `FragmentProgram?`, null when it failed to load or effects are off) and `effects` (bool). A factory `ToyLook.build({required ToyPalette palette, required bool tv, ToyShaders shaders = ToyShaders.none, bool effects = true})` puts them together; `shade` is null when `effects` is false. It has == and hashCode (all fields) so a scope only rebuilds on a change. `ToyLookScope` is an InheritedWidget holding a ToyLook with `static ToyLook of(BuildContext)` (asserts one is above) and `updateShouldNotify` on inequality. Painters take the ToyLook value (D5); only widgets use the scope.

9. The contrast test (PRD M13 acceptance, design section 3): one test over both palettes and every text-on-fill pair: ink on paper; onBackground on background, backgroundGlow, board, tray and field; ink on player(1..6), good, caution, bad, focus, faceA, faceB, faceX and faceY. Each is at least 4.5:1 by the WCAG 2 formula (relative luminance with the 0.03928 threshold), and a failure names the palette, the pair and the ratio. The test also checks the formula itself against Claude's values: Sunny ink on paper 15.53, Sunny ink on player 3 4.94, Night white on background 14.97 (each to 2 decimals).
