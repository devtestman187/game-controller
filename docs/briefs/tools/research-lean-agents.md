You cannot read our repository, so here is everything about our setup.

**What flash-worker is.** A bash script (`tools/flash.sh`) that runs one job with Claude Code in headless mode: `claude --bare -p "<task>" --model deepseek-v4-flash --permission-mode acceptEdits --append-system-prompt "<about 15 lines of rules>" --allowedTools <Read, Edit and about 20 Bash(...) patterns> --disallowedTools <Agent, Task, WebFetch, WebSearch and many Edit/Read/Bash patterns> --output-format json`, with `ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic` and the DeepSeek key supplied by an `apiKeyHelper`. So the agent loop is Claude Code's own; the model is DeepSeek's through its Anthropic-compatible endpoint. Each job runs in its own git worktree on Windows (Git Bash), reads a brief file (60–120 lines) and several source and document files, edits code, runs tests, and writes a report. Subagents are disabled. We do not control the loop, only the command line, environment variables, settings and the brief.

**Measured use over 193 jobs (Nov 6–11, 2026), from each run's JSON result:**
- 38,754 turns in total; 201 turns per job on average (107 jobs had 150 or more turns).
- Input tokens not from cache: 33.7 M. Input tokens read from cache: 2,770 M (98.8% of all input). Cache-write: 0 reported. Output: 20.4 M.
- Cache-read per turn averages 71 k tokens, and grows with job length: 44 k/turn in jobs of 30–79 turns, 63 k in 80–149, 75 k in 150+. The largest single job read 93.7 M cached tokens.
So nearly all the volume is the conversation prefix being re-sent each turn and served from DeepSeek's context cache.
