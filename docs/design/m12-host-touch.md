# M12: the host phone's menus are touch-only (owner's decision, Nov 7, 2026)

The owner: "Having touch controls (eg being able to touch UX elements like game type) while having the gamepads up is confusing. Would it make sense to disable the gamepads while not in game when in phone hosted mode?" Claude proposed the rules below; the owner: "Yes your plan for the hiding the pad is good."

This replaces m12.md §3's "the screens already work by touch, remote focus and controller menus, so the host phone's owner can use either" for the host phone's own pad.

## The rules (the host phone in "Play on this phone")
1. **Outside a round, no pad.** The game picker, the level list, the join screen, the results, the settings and the pause menu are plain touch screens with nothing drawn over them, and the top bar is the full one.
2. **During a round, the pad.** It comes up when the round starts, as today, see-through over the game; touches go to the pad only.
3. **A "Get ready" beat** when a round starts (the countdown), so thumbs find the pad before the clock runs.
4. **Pausing:** Start on the pad opens the pause menu, which is touch-only with the pad hidden; Resume brings the pad back. The away card (bug 1107d) and the host-away pause are touch on the host phone too.
5. **The host's own player joins by itself.** On the join screen the host phone's player is in from the start; tapping a side picks or changes it. The other players still join with A on their phones.
6. **Unchanged:** joined phones keep their pad all the time (it is how they work the host's menus); "Show on this device" already has no pad; the TV and its phones are unchanged.
